# Story template

Six acts. One hero use case shown end to end, then a ladder of bigger builds, then a montage. Times are seconds at the reference length (99s); budgets for shorter cuts below.

## Acts

| # | Act | 99s ref | Job | Moves |
|---|---|---|---|---|
| 1 | Open | 0-6 | Brand on black and smoke | D01 |
| 2 | Name | 6-14 | "Introducing" → feature name → into the app | D02, D03, D04, D05, D06, D07 |
| 3 | Hero demo | 14-42 | One simple use case, prompt to working result, then using it | D03, D08, D09, D10, D11, D12, D13 |
| 4 | Escalation | 42-64 | "What about something more ADVANCED?" then 2-3 rungs, each card + result | D14, D15, D13, D20 |
| 5 | Payoff | 64-90 | "Ultimately, ..." then "Everything / Everywhere / All At Once" over a fast montage | D14, D16, D17, D18, D19, D20 |
| 6 | Close | 90-99 | Tagline on black, logo on white | D02, D21, D22 |

## Budgets by runtime

| Act | 45s | 60s | 90-100s |

Under 45s: drop the escalation to one rung and the payoff to "Everything" + 4 clips.

## Hero demo beats (act 3)

1. Card: "<Action>, **Instantly**" (D03, accent flip). 1.5-2s.
2. Push-through into the composer (D08). Prompt types (D09). Camera swings to the send button, click.
3. Dot to pill, agent log (D10, D11). 3-5s. The log shows real-sounding steps, not lorem.
4. Result (D12): the built thing works, with one visible state change.
5. Card: "Ready to Use, **Instantly**" (D03). 1.5s.
6. Cursor opens it from the product's own navigation (D07), window on smoke (D13), someone uses it (D12).

Optionally run a second, faster use case through steps 2-4 before step 5 (the reference builds a timer, then a sticky-note wall).

## Ladder (act 4)

- Card 1: lead-in "What about something more" + punch "**ADVANCED?**" (D14).
- Rungs: "Like A **<thing>?**", "Or A **<bigger thing>?**", "Even A **<absurd thing>?**". The connector word changes each rung (Like / Or / Even), the payoff phrase is accent and slot-rolls (D15).
- After each rung: 3-5s of that thing working (D13 or D20). The cursor changes one setting so it reads as live.

## Payoff (act 5)

- "Ultimately," + "**Your Own <Product noun>**" (D14).
- 3-4 montage clips (D20).
- "With <Feature>, You Can Create" typed (D03), then "Everything" with the UI orbit (D16).
- 4-6 montage clips, cuts accelerating.
- "Everywhere" with scene corners (D17), 2-3 clips.
- "All At Once" in wave letters (D18), blur-scale punch out (D19).

## Copy rules

- Every card is one short line in Title Case, 2-6 words, ending on the payoff word. No sentences, no periods.
- Lead-ins are lower-case after the first word and end in a comma or nothing: "Ultimately,", "What about something more".
- Escalation rungs are questions. Payoff lines are statements.
- The tagline is "<Feature>, <Verb> Your Own <Noun>" or the user's own line.
- Prompts in the composer are casual and specific ("make a clock-out countdown plugin for me"), lower-case, 5-12 words.
- Use the user's copy verbatim where they gave it. Flag every line you wrote.
